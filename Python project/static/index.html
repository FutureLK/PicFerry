Pixiv 收藏查重
如何获取 Pixiv UID：
  1. 打开 pixiv.net 并登录
  2. 点击右上角头像进入个人主页
  3. 浏览器地址栏 https://www.pixiv.net/users/12345678 末尾的数字即是 UID
如何获取 PHPSESSID：
  1. 在浏览器打开 pixiv.net 并登录账号
  2. 按 F12 打开开发者工具
  3. 切换到 Application 标签 → 左侧 Cookies → https://www.pixiv.net
  4. 找到 PHPSESSID 这一行，复制其值（一串字母数字）
⚠ PHPSESSID 相当于你的登录凭证，不会上传到任何第三方服务器
