# 图片同步

局域网文件比对与传输工具。支持 HTTP/FTP 连接两台手机，扫描去重后一键同步。

## 功能一览

| 功能 | 说明 |
|---|---|
| 双协议 | HTTP 目录列表解析 + FTP 直连（MT 管理器免配对码） |
| 本地路径 | 直接扫描本地磁盘目录（`C:\Users\...\Pictures` 等） |
| 双向查重 | B→A 正向 / A→B 反向，一键切换 |
| 哈希校验 | SHA256 比对文件内容，可选开启 |
| 标签页界面 | 设备同步 / Pixiv 查重 / 更多设置 / 日志 四个标签页，源码留 TABS 注册接口 |
| Pixiv 后台扫描 | 可随时终止、可选数量上限、实时进度轮询 |
| 分p级查重 | 按书签作品页数（pageCount）逐分p匹配，结果表显示命中分p |
| Pixiv 黑名单 | `blacklist.csv` 作品 ID 黑名单，拉取阶段直接剔除 |
| 网页彩色日志 | 终端/网页双端实时显示 `[SCAN]/[HASH]/[SYNC]/[DONE]/[ERROR]` 带颜色，可暂停/清空/自动滚动 |
| 缩略图预览 | 懒加载（IntersectionObserver）+ 尺寸可调（16-128px） |
| 悬浮大图 | 鼠标悬停文件名弹出预览面板，自动避让视口，延迟可调 |
| 输入智能识别 | 类型徽标（HTTP/FTP/本地）、无协议地址自动补全、Pixiv 链接提取 UID |
| 可调控件 | 缩略图尺寸 / 预览延迟 / Pixiv 请求间隔 / 结果行数上限，持久化到 config.ini |
| 设备统计 | 扫描后显示每台设备的文件总数和总大小 |
| 逐行动画 | 扫描结果 fadeIn 渐现 + 交错延迟 |
| 日志文件 | 同目录 `sync.log`，防止终端输出丢失 |
| 图片代理 | `/api/image` 转发远程图片供浏览器直接展示 |
| 单文件打包 | PyInstaller → 6.7 MB，零依赖 |

## 快速开始

```
cd "Python project"
python server.py
```

或双击 `Python project/dist/图片同步.exe`。
