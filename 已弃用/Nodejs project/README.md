# 📷 图库同步工具 — Gallery Sync Tool

通过**局域网**在两台手机之间同步图库图片。支持 HTTP 和 FTP 两种连接方式。

## 🎯 它能做什么

你有两台手机，都用 Pixez（或其他 Pixiv 第三方客户端）保存插画，但两台手机的图库不同步。

这个工具帮你：
1. **扫描** — 拉取两台手机图库的文件列表
2. **去重** — 自动找出"备用机有、主力机没有"的图片
3. **同步** — 一键把新图片复制到主力机

## 📦 使用方式

### 方式一：EXE（推荐，无需装任何东西）

把 `dist/gallery-sync.exe` 发给谁都能用。

> 注意：第一次运行可能被 Windows 安全中心拦截，点击「更多信息」→「仍要运行」即可。

```
双击 gallery-sync.exe
→ 浏览器自动打开 http://localhost:3000
→ 开始使用
```

### 方式二：源码运行（适合修改代码）

需要安装 [Node.js](https://nodejs.org/)（免费）。

```bash
npm install        # 安装依赖（只需一次）
node server.js     # 启动服务
```

浏览器自动打开 `http://localhost:3000`

## 🖥️ 界面操作

| 步骤 | 说明 |
|---|---|
| **① 填链接** | 输入两台手机的 HTTP 或 FTP 链接 |
| **② 点扫描** | 点击「扫描比对」，自动拉取两个目录的图片列表 |
| **③ 看结果** | 列表显示"备用机有、主力机没有"的图片 |
| **④ 选文件** | 勾选要同步的图片（默认全选） |
| **⑤ 点同步** | 点击「同步到设备1」，开始复制 |

> **可选：** 开启「哈希校验」对同名文件做 SHA256 内容比对，更准确但速度会慢一些。

## 📱 手机端设置

### 方式一：FTP（推荐）

MT 管理器 / MiXplorer 等文件管理器都有 FTP 服务功能：

1. 打开文件管理器 → 远程管理 → 启动 FTP
2. 记下显示的地址，如 `ftp://192.168.1.100:21/`
3. 在电脑浏览器输入这个地址确认能访问
4. 填入工具输入框（注意路径要指向图片文件夹）

> MT 管理器的 FTP **不需要配对码**，开箱即用。

### 方式二：HTTP

部分文件管理器支持 HTTP 远程访问：

1. 打开远程管理 → 启动 HTTP 服务
2. 记下地址，如 `http://192.168.1.100:1234/`
3. 填入工具输入框

> 注意：MT 管理器的 HTTP 需要配对码，建议用 FTP。

### 注意事项

- 两台手机和电脑必须在**同一个局域网**（连同一个 WiFi）
- 输入路径要指向**图片所在的目录**（如 `/DCIM/Pixez/`）
- 同步是**复制**，不会删除手机上的任何文件

## 🔧 常见问题

### Q: 提示无法连接设备？
- 确认手机和电脑在同一个 WiFi
- 确认手机的 FTP/HTTP 服务已开启
- 确认防火墙没有阻挡连接
- 在电脑浏览器直接输入手机地址测试能否访问

### Q: 扫描出来的文件列表为空？
- 确认链接末尾的路径正确（如 `/DCIM/Pixez/`）
- 确认目录里有图片文件（.jpg / .png / .gif / .webp）

### Q: 同步失败？
- 确认设备1（主力机）的 FTP/HTTP 服务支持写入（上传文件）
- 部分文件管理器的 HTTP 服务可能不支持 PUT 上传，建议改用 FTP

### Q: 端口 3000 被占用？
- 关闭其他占用 3000 端口的程序
- 或在 `server.js` 中修改 `PORT = 3000` 为其他值

## 🛠️ 打包成 EXE

## 📄 技术说明

- 纯**局域网**操作，图片不经过互联网
- Node.js **代理服务器**解决浏览器跨域限制
- 支持 HTTP（目录列表 HTML 解析）和 FTP 协议
- 按**文件名**去重（Pixez 文件名含 pixiv ID，足够区分）
- 可选 **SHA256 哈希**验证同名文件的内容一致性
- 文件传输使用流式处理，不会在硬盘上生成临时文件
- 用 `pkg` 打包成独立 EXE，无需 Node.js 环境
